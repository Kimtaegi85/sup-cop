윈도우 상주 세팅 (인수인계용)

이 PC에서 24시간 돌리기 위한 체크리스트. 순서대로 하면 된다.

  1. Chrome 설치 → Tampermonkey 설치 → chrome://extensions 에서 Tampermonkey “Allow User Scripts” 켜기 (안 켜면 스크립트가 안 돎)
  2. 이 페이지에서 스크립트 받기 → Tampermonkey 대시보드 → 새 스크립트에 전체 붙여넣기 → 저장 → @match 4줄 확인
  3. 크롬 바탕화면 바로가기 → 속성 → 대상 끝에 아래 플래그 추가
    --disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows
    (백그라운드 탭 타이머가 1분으로 줄면 드랍 타이밍이 깨진다)
  4. 전원 옵션: 절전·화면 끄기 모두 사용 안 함, 자동 로그인 켜기, 크롬 종료 방지
  5. 이 페이지에서 배송지/카드 저장 → 휴대폰 트리거 토큰 저장 → 감시 시작(스크립트)로 스토어 탭 생성
  6. 스토어 탭은 앞에 두고 다른 창을 최소화. 크롬 최소화는 타이머에 영향 없지만 탭이 숨으면 안 됨

드랍은 목요일 11:00 뉴욕(한국 금요일 01:00). ARM은 T-5~7분(한국 00:53~00:55)에. 3DS·앱 승인은 폰으로 본인이 처리.

감시 / 자동 구매

줄 형식: 키워드1|키워드2;핸들;사이즈1|사이즈2 — 핸들이 있으면 그 색만, 사이즈 비우면 아무 사이즈.

Cybersole 권장값(Supreme): T-5~7분에 시작, 지연 10초 → T-15초에 2.5초, Safe Preload(대기열 있는 예약 드랍) 모드. 우리도 같은 값으로 맞췄습니다. ISP 프록시는 드랍 때 거의 안 되고 로컬 IP 2개 + 주거용 프록시가 권장입니다.

스크립트 없이도 여기서 감시하고 목표가 뜨면 결제창까지 링크로 넘길 수 있습니다. 스크립트를 쓰면 카트담기·입력·제출까지 자동입니다.
